# AuraAlarm - Custom Alarm Web Application

AuraAlarm is a production-ready, high-performance web-based scheduling and custom alarm system built with modern vanilla architecture. It allows users to create alarms, toggle options for advanced Text-to-Speech (TTS) voice scripts, upload native audio blobs, and pull contextual morning news briefing streams without external heavy framework dependencies.

Developed with modular core layers ensuring zero system bloat, fast load performance, and robust state containment.

---

## Key Features

* **High-Precision Ticker Engine:** Real-time state validation down to the boundary second.
* **Advanced Audio Engine:** Employs Web Audio API configurations supporting local binary audio uploads and cloud-based presets seamlessly.
* **TTS Voice Personalization:** Deep integrations with native browser `SpeechSynthesis` pipelines to speak custom greetings.
* **Daily Briefing Streams:** Integrated pipeline for custom simulated news update playback directly following alarm executions.
* **State Persistence & Storage:** Secure local operations utilizing `localStorage` caching mechanics.
* **Fluid Responsive UX:** Designed via Dark Mode-First tokens optimized across desktop, tablet, and mobile displays.
